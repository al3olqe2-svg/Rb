# Stage 5 — 0.5.0 (5)

## النتيجة
- Stable Capture: لا تُضاف قراءة الكاميرا تلقائيًا. نافذة 7 إطارات، وقراءتا باركود أو 3 قراءات OCR متفقة، مع استبعاد أجزاء الرقم الأطول. تكرار مرشحين مختلفين يبقيهما منفصلين في قائمة ثابتة؛ الأولوية البصرية للباركود ولا اختيار صامت عند التعارض.
- التثبيت قابل للضبط في TemporalCapture؛ يستمر حتى التأكيد أو إعادة المسح، وتُستبعد أرقام الجلسة من الالتقاط التالي. تُمسح الأدلة عند فجوة 2500ms. CameraX يحتفظ بإطار واحد قيد المعالجة مع فاصل 450ms وموارد ML Kit محلية.
- OCR ذو 19–20 خانة يحتاج 3 قراءات؛ الأطوال غير القياسية تحتاج 5 قراءات مع تنبيه بمطابقة الرقم كاملًا. تبقى متاحة كذلك بباركود متكرر أو إدخال مؤكد يدويًا. لا تتحول أجزاء رقم مؤكد في الجلسة إلى مرشح جديد. وضع المجموعة مستقل ويدعم 1–64 خانة، بما فيها الأصفار.
- «إضافة سلسلة» أعلى شاشة المسح: أدخل/امسح الرقم الأول، أدخل آخر أربع خانات للنهاية، راجع العدد وأول/آخر رقم، ثم أضف للمراجعة واحفظ الدفعة. المثال 8985–8999 = 15. BigInteger يحافظ على جميع الخانات، الحد 500، والنهاية الأصغر مرفوضة دون تخمين الالتفاف أو تغيير خانة التحقق.
- السلاسل والكاميرا والإدخال اليدوي تشترك في ScanSession وreviewScan/saveScan. النقل لا يحدث دون تحديد الموافقة، وحذف صف من المراجعة لا يمس المخزون.
- نموذج إنشاء المجموعة مضغوط مع زر مسح، دون الشروحات السابقة. آخر أربع خانات بارزة والرقم الكامل محفوظ وظاهر.
- نجاح المعاملة ينتقل مباشرة إلى المجموعة أو الأرشيف مع Snackbar؛ popUpTo يمنع نسخ تفاصيل المجموعة المتكررة. الفشل يبقي الجلسة والمراجعة.

## سلامة البيانات
com.rb.app وrb.db وRoom schema v1 مطابقة للمرحلة الرابعة، ولا migration مدمرة أو صلاحية إنترنت أو صور محفوظة. المعرف الكامل فريد؛ الأعداد مشتقة من الاستعلامات. معاملات المخزون والتعارضات والتصدير القائمة محفوظة. اختبار السلسلة يراجع النقل المقبول والمرفوض وإزالة صف وتكرار صف ممسوح في الجلسة نفسها. اختبار Excel يفحص كل رقم مولد كخلية نصية في الورقتين.

## التحقق
- JDK 17 وAndroid SDK/Build Tools 36؛ ./gradlew testDebugUnitTest lintDebug assembleDebug.
- 93 اختبارًا: صفر فشل/تجاهل؛ اختبارات Room وعمليات المخزون السابقة على API 26 و35، واختبارات الواجهات والتنقل والحفظ الفاشل والإجماع الزمني والسلاسل والتصدير.
- Lint: صفر أخطاء، ثلاثة تنبيهات تحديث مكتبات موجودة سابقًا. البناء ينتج Debug APK.
- البيئة المحلية تحتاج إعداد proxy وشهادة النظام لعامل Robolectric في init script خارجي؛ لا تُضمّن إعدادات هذه البيئة في المشروع.
- Actions ينفذ الفحوص نفسها، ثم تثبيت APK وتشغيله وإعادة تثبيته بنفس التوقيع على محاكي API 26، ويرفع APK ولقطة الجهاز والسجلات وتقارير الاختبارات وLint. نتائج التشغيل الفعلية متاحة في Checks لطلب الدمج #5.
- فحص APK باستخدام apksigner وzipalign وaapt: توقيع v2 صالح، الحزمة والإصدار صحيحان، minSdk=26، ولا INTERNET أو صلاحيات تخزين واسعة.
