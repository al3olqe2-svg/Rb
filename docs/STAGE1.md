# Stage 1 — تقرير التسليم

## النتيجة

تطبيق Android أصلي، Android 8.0 / API 26 كحد أدنى، وtarget/compile SDK 36. أُنجز إنشاء المجموعات والتحقق من المدخلات وتخزينها محليًا وتعديل المسؤول وعرض الأعداد الفعلية وحذف المجموعة الفارغة فقط بعد التأكيد. أُنجز عرض شرائح المجموعة مع الرقم الكامل وآخر أربع خانات. لا توجد بيانات تجريبية في التطبيق.

شاشات المسح والأرشيف والبحث وجهات توضيحية صريحة فقط. لا كاميرا أو OCR أو نقل أو تصدير أو مزامنة في هذه المرحلة. لم تُعدّل ملفات PRD.md وAGENTS.md.

## التحقق المنفّذ — 2026-11-13

```sh
./gradlew testDebugUnitTest lintDebug assembleDebug
```

النتيجة: BUILD SUCCESSFUL. نجحت 17 حالة اختبار دون فشل:

- 7 حالات Room/Repository على API 26 ومثلها على API 35: الإنشاء، الأصفار، تطبيع الأرقام العربية والفارسية، منع التكرار، تعديل المسؤول مع ثبات المعرف والرقم، أعداد المجموعات والأرشيف، الأرقام الطويلة، تشابه آخر أربع خانات، FK، منع حذف المجموعة المملوءة، ذرية الدفعة، واستمرار البيانات بعد إغلاق قاعدة بيانات على القرص وإعادة فتحها.
- حالتا Compose على API 35: التنقل وإنشاء مجموعة وتعديلها وإلغاء حذفها ثم حذفها، وعرض الرقمين الكاملين مع تطابق آخر أربع خانات ومنع حذف مجموعتهما.
- حالة تشغيل MainActivity الفعلية وإعادة إنشائها مع بقاء المجموعة ظاهرة.

فحص Lint ناجح دون أخطاء. توجد تنبيهات تحديث للفروع الأحدث من Lifecycle وNavigation؛ سبب تثبيت الفروع المتوافقة موثق في README. اختبارات Compose تستخدم API اختبار لا يزال مدعومًا مع تنبيه deprecation في الإصدار الحالي.

تم فحص لقطات الواجهة الناتجة من الرسم الأصلي في Robolectric. ملفاتها وتقارير الاختبارات متاحة ضمن `app/build/reports` وتُرفع في CI.

أُنتج `app/build/outputs/apk/debug/app-debug.apk` (نحو 19 MB). تحقق `apksigner verify` نجح بتوقيع v2، وفُحص manifest داخل APK: minSdk 26، targetSdk 36، ولا صلاحية إنترنت أو كاميرا.

## التثبيت والقيود

نزّل artifact باسم `Rb-stage1-debug` من تشغيل Android الناجح في GitHub Actions وفك ضغطه وثبّت APK، أو ابنِ المشروع حسب README واستخدم `adb install -r app/build/outputs/apk/debug/app-debug.apk`.

لم يُنفّذ تثبيت على هاتف فعلي أو اختبار إغلاق قسري لعملية Android وإعادة تشغيلها. الاختبارات المنفّذة تشمل إعادة إنشاء النشاط وإعادة فتح قاعدة البيانات على القرص؛ لا تُقدَّم بوصفها اختبار جهاز حقيقي. نسخة APK هي Debug للتطوير، وليست إصدار متجر.
