# Rb — Android

تطبيق Android أصلي لإدارة شرائح SIM محليًا. المراحل الأولى حتى السادسة: المجموعات، ماسح CameraX وBarcode/OCR محلي، ومراجعة وحفظ جماعي، وإدارة المخزون الفعلي. تصدير Excel وتحسينات الواجهة في [تقرير المرحلة الرابعة](docs/STAGE4.md). تفاصيل الإدارة والتحقق في [تقرير المرحلة الثالثة](docs/STAGE3.md)، والمسح واختبار الهاتف في [تقرير المرحلة الثانية](docs/STAGE2.md). راجع [PRD.md](PRD.md) و[AGENTS.md](AGENTS.md).

## البناء والتثبيت

يتطلب JDK 17، وAndroid SDK Platform 36 وBuild Tools 36.0.0. الحد الأدنى للتثبيت Android 8.0 (API 26).

افتح المستودع في Android Studio أو عيّن `ANDROID_HOME` إلى مسار SDK. يمكن أيضًا استخدام `sdk.dir` في ملف `local.properties` محلي غير محفوظ في Git. لا يتطلب المشروع مفاتيح API أو خدمات خارجية.

```sh
./gradlew testDebugUnitTest lintDebug assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

أو نزّل `Rb-stage4-debug` من صفحة تشغيل **Android** في GitHub Actions، فك الضغط وثبّت APK مع السماح بالتثبيت من المصدر المستخدم. نسخة Debug مخصصة للتجربة والتطوير، وليست إصدار متجر موقّعًا بمفتاح إنتاج.

إصدارات البناء مثبتة: AGP 8.13.2، Gradle 8.14.7، Kotlin 2.3.21، KSP 2.3.14، Compose BOM 2026.06.01، وRoom 2.8.5. اختيرت فروع AndroidX المتوافقة مع SDK 36 وAGP 8 بعد فحص AAR metadata؛ Compose 1.12 وLifecycle 2.11 وNavigation 2.10 تتطلب SDK 37 وAGP 9.1 أو أحدث، لذا تحتاج ترقيتها إلى تحديث سلسلة البناء معًا.

## المنفّذ

- واجهة عربية RTL فاتحة، أرقام ثابتة العرض باتجاه LTR، وقوائم LazyColumn بمفاتيح ثابتة.
- إنشاء المجموعات، منع التكرار، تعديل المسؤول، عرض الأعداد الحقيقية وإجمالي الشرائح بما فيها الأرشيف.
- عرض شرائح المجموعة مع آخر أربع خانات والرقم الكامل، مع التفاصيل ونسخ الرقم والفرز الرقمي والتحديد الفردي والجماعي والنطاق.
- حذف المجموعة الفارغة بعد تأكيد؛ الحذف محمي أيضًا باستعلام ذري وقيد Foreign Key.
- المسح المتتابع بالكاميرا، مراجعة الأرقام وتصحيحها، الحفظ الجماعي الذري، والنقل أثناء المسح بعد موافقة لكل شريحة. نقل وأرشفة وحذف مؤكد للشرائح، وأرشيف عام حقيقي وبحث جزئي مباشر يعرض كل المطابقات ومواقعها. تصدير XLSX بورقتين عبر منتقي ملفات Android، مع فتح الملف أو مشاركته وحماية الأرقام الطويلة وأصفار البداية.

## البنية والبيانات

`data/Database.kt`: كيانات Room وDAO ومخطط الإصدار 2 وترحيل آمن من الإصدار 1، المحفوظين في `app/schemas`. معرّفات UUID مستقلة؛ `code` و`serial` نصوص فريدة. لا تُخزّن الأعداد أو `last4`. مرجع المجموعة اختياري ومفهرس؛ `RESTRICT` يمنع حذف مجموعة مرتبطة بشرائح.

`data/InventoryRepository.kt`: التحقق من المدخلات وعمليات المجموعات. مراجعة مواقع الشرائح وخطة الحفظ، وإدراج الجديدة ونقل الموافق عليها فقط داخل معاملة واحدة مع إعادة التحقق من المواقع والوجهة. لا نقل ضمني ولا حفظ جزئي ولا بيانات تجريبية.

`export/`: كاتب OOXML متدفق باستعمال ZIP المدمج دون مكتبات إنتاج إضافية، وحالة تصدير مستقلة وكتابة SAF خارج خيط الواجهة. قراءة لقطة المخزون من معاملة Room واحدة.

`scanner/`: المحلل وCameraX واستخراج المرشحين والجلسة وشاشة المراجعة، مع ScannerViewModel وSavedStateHandle.

`ui/StockScreen.kt` و`ui/StockViewModel.kt`: قائمة مشتركة للمجموعة والأرشيف والبحث، والتحديد بالمعرّف وحوارات العمليات.

`ui/InventoryViewModel.kt`: الحالة عبر StateFlow، والمراقبة المراعية لدورة الحياة، وعمليات الحفظ خارج Composables. `ui/Theme.kt` و`ui/RbApp.kt`: الهوية والمكونات المشتركة والتنقل والشاشات.

تُطبّع خانات لوحة المفاتيح العربية والفارسية إلى ASCII كنص؛ `0055` يبقى مختلفًا عن `55`. حدود الإدخال: رقم مجموعة 1–64 خانة، واسم مسؤول 1–120 حرفًا بعد إزالة المسافات الطرفية. لا يُفترض طول ثابت للرقم التسلسلي.

التخزين محلي، دون صلاحية إنترنت، ودون نسخ احتياطي سحابي تلقائي. لا تُستخدم destructive migrations. عند تغيير المخطط مستقبلًا يجب إضافة migration واختبارها.

## الاختبارات

اختبارات JVM عبر Robolectric وRoom الحقيقي: إنشاء وحفظ المجموعات، التفرد، الأصفار، تعديل المسؤول، العلاقات، أعداد الشرائح والأرشيف، تساوي آخر أربع خانات، منع الحذف، ذرية الدفعة، وإعادة فتح قاعدة بيانات على القرص. اختبار Compose يجرب وجهات التنقل وإنشاء مجموعة وتعديلها وإلغاء حذفها ثم حذفها ومنع حذف مجموعة مرتبطة بشرائح. اختبار مستقل يشغّل MainActivity الفعلية ويعيد إنشاءها للتحقق من بقاء المجموعة في الواجهة. تُنتج اختبارات الواجهة لقطات في `app/build/reports/screenshots`.

تحتاج أول مرة إلى الإنترنت لتنزيل Gradle والمكتبات وصورة Android الخاصة بـRobolectric. التطبيق نفسه يعمل دون اتصال. اختبارات Robolectric لا تستبدل تجربة APK على جهاز Android فعلي.

تنبيه التحديث: احتفظ بالتطبيق وبياناته إذا اختلف توقيع APK؛ لا تحذفه لحل تعارض التوقيع. اقرأ قسم APK والتوقيع في [تقرير المرحلة الثانية](docs/STAGE2.md).


## Stage 6
من قائمة التطبيق افتح **سجل النقل**؛ اضغط العملية لرؤية المصدر والوجهة والتاريخ وجميع الأرقام ونسخها. يسجل النقل بين مجموعتين فقط منذ تثبيت هذا التحديث، حتى عند النقل أثناء حفظ مسح بعد الموافقة.

في إنشاء المجموعة، زر الكاميرا يفتح **GroupLabelScanner**: أظهر الملصق كاملًا مع الباركودين والنص. يظهر الرقم العلوي أولًا عند اتفاق الأدلة المكانية والنصية؛ عند الالتباس اختر يدويًا من القائمة المثبتة. راجع الرقم الكامل وأكّده، ويمكن تعديله في النموذج قبل الحفظ. التفاصيل والاختبارات والتوقيع في [تقرير Stage 6](docs/STAGE6.md).
