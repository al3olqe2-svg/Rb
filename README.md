# Rb — Android

تطبيق Android أصلي لإدارة شرائح SIM محليًا. المرحلة الأولى: المجموعات والأساس التقني فقط. راجع [PRD.md](PRD.md) و[AGENTS.md](AGENTS.md).

## البناء والتثبيت

يتطلب JDK 17، وAndroid SDK Platform 36 وBuild Tools 36.0.0. الحد الأدنى للتثبيت Android 8.0 (API 26).

افتح المستودع في Android Studio أو عيّن `ANDROID_HOME` إلى مسار SDK. يمكن أيضًا استخدام `sdk.dir` في ملف `local.properties` محلي غير محفوظ في Git. لا يتطلب المشروع مفاتيح API أو خدمات خارجية.

```sh
./gradlew testDebugUnitTest lintDebug assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

أو نزّل `Rb-stage1-debug` من صفحة تشغيل **Android** في GitHub Actions، فك الضغط وثبّت APK مع السماح بالتثبيت من المصدر المستخدم. نسخة Debug مخصصة للتجربة والتطوير، وليست إصدار متجر موقّعًا بمفتاح إنتاج.

إصدارات البناء مثبتة: AGP 8.13.2، Gradle 8.14.7، Kotlin 2.3.21، KSP 2.3.14، Compose BOM 2026.06.01، وRoom 2.8.5. اختيرت فروع AndroidX المتوافقة مع SDK 36 وAGP 8 بعد فحص AAR metadata؛ Compose 1.12 وLifecycle 2.11 وNavigation 2.10 تتطلب SDK 37 وAGP 9.1 أو أحدث، لذا تحتاج ترقيتها إلى تحديث سلسلة البناء معًا.

## المنفّذ

- واجهة عربية RTL فاتحة، أرقام ثابتة العرض باتجاه LTR، وقوائم LazyColumn بمفاتيح ثابتة.
- إنشاء المجموعات، منع التكرار، تعديل المسؤول، عرض الأعداد الحقيقية وإجمالي الشرائح بما فيها الأرشيف.
- عرض شرائح المجموعة مع آخر أربع خانات والرقم الكامل القابل للتحديد والنسخ.
- حذف المجموعة الفارغة بعد تأكيد؛ الحذف محمي أيضًا باستعلام ذري وقيد Foreign Key.
- وجهات المسح والأرشيف والبحث توضح صراحة أنها مؤجلة. لا توجد وظائف كاميرا أو نقل أو بحث أو تصدير.

## البنية والبيانات

`data/Database.kt`: كيانات Room وDAO ومخطط الإصدار 1 المحفوظ في `app/schemas`. معرّفات UUID مستقلة؛ `code` و`serial` نصوص فريدة. لا تُخزّن الأعداد أو `last4`. مرجع المجموعة اختياري ومفهرس؛ `RESTRICT` يمنع حذف مجموعة مرتبطة بشرائح.

`data/InventoryRepository.kt`: التحقق من المدخلات وعمليات المجموعات. تجهيز المرحلة الثانية: الاستعلام عن الأرقام الموجودة وإضافة أرقام جديدة في معاملة واحدة، مع رفض أي تعارض دون نقل ضمني أو حفظ جزئي. ليست هناك واجهة لإضافة الشرائح في المرحلة الأولى ولا بيانات تجريبية.

`ui/InventoryViewModel.kt`: الحالة عبر StateFlow، والمراقبة المراعية لدورة الحياة، وعمليات الحفظ خارج Composables. `ui/Theme.kt` و`ui/RbApp.kt`: الهوية والمكونات المشتركة والتنقل والشاشات.

تُطبّع خانات لوحة المفاتيح العربية والفارسية إلى ASCII كنص؛ `0055` يبقى مختلفًا عن `55`. حدود الإدخال: رقم مجموعة 1–64 خانة، واسم مسؤول 1–120 حرفًا بعد إزالة المسافات الطرفية. لا يُفترض طول ثابت للرقم التسلسلي.

التخزين محلي، دون صلاحية إنترنت، ودون نسخ احتياطي سحابي تلقائي. لا تُستخدم destructive migrations. عند تغيير المخطط مستقبلًا يجب إضافة migration واختبارها.

## الاختبارات

اختبارات JVM عبر Robolectric وRoom الحقيقي: إنشاء وحفظ المجموعات، التفرد، الأصفار، تعديل المسؤول، العلاقات، أعداد الشرائح والأرشيف، تساوي آخر أربع خانات، منع الحذف، ذرية الدفعة، وإعادة فتح قاعدة بيانات على القرص. اختبار Compose يجرب وجهات التنقل وإنشاء مجموعة وتعديلها وإلغاء حذفها ثم حذفها ومنع حذف مجموعة مرتبطة بشرائح. اختبار مستقل يشغّل MainActivity الفعلية ويعيد إنشاءها للتحقق من بقاء المجموعة في الواجهة. تُنتج اختبارات الواجهة لقطات في `app/build/reports/screenshots`.

تحتاج أول مرة إلى الإنترنت لتنزيل Gradle والمكتبات وصورة Android الخاصة بـRobolectric. التطبيق نفسه يعمل دون اتصال. اختبارات Robolectric لا تستبدل تجربة APK على جهاز Android فعلي.
